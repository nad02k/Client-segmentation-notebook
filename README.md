# Customer Segmentation — Online Retail

## 📌 Objectif
Segmentation clients pour identifier :
- Les clients les plus précieux (VIP)
- Les clients inactifs depuis 6 mois
- Les segments qui génèrent le plus de CA
- Les clients à risque de partir

## 📦 Dataset
- Source : [UCI Online Retail](https://www.kaggle.com/datasets/ulrikthygepedersen/online-retail-dataset)
- Période : Décembre 2009 – Décembre 2011
- ~1 million de transactions
